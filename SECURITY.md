# Segurança

Use HTTPS, PDO MySQL com consultas parametrizadas, sessões HttpOnly/SameSite, CSRF, Argon2id, MFA administrativo e armazenamento privado. Não compartilhe credenciais, exportações ou dados pessoais. Notifique falhas de forma privada. A homologação e revisão LGPD são obrigatórias antes da produção.
