# SERÁ QUEM FAZ? — v3.9.17

## Novidades
- Reorganização do perfil de cliente: dados pessoais, edição, atividades e menu lateral responsivo.
- Solicitações LGPD movidas da edição do perfil para **Configurações**.
- Fotografias JPG, PNG e WebP com tamanho máximo de **5 MB**, sem exigência mínima de resolução.
- Tratamento e conversão de fotografias em WebP, com remoção de metadados, mantendo armazenamento privado e políticas RLS.
- Mensagens mais claras de erro de cadastro e de limite HTTP 429; envio de e-mails de confirmação depende de SMTP próprio no Supabase.

## Arquivos para download
- `SeraQuemFaz_site_v3.9.17.zip`: versão estática para publicação em servidor web.
- `SeraQuemFaz_codigo_v3.9.17.zip`: projeto completo com fontes, documentação e testes.

## Observações
Esta versão registra o código histórico da v3.9.17. Recomendamos a v3.10.0 para novas instalações. A implantação em produção depende das configurações de segurança, do Supabase e da homologação funcional.
