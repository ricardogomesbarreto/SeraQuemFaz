# SERÁ QUEM FAZ? — v3.3.3

Versão local com 32 fotografias sintéticas fotorrealistas de prestadores em cenários de trabalho correspondentes. A imagem de cada categoria aparece tanto no catálogo quanto na página do serviço. Há fallback local para novos nomes sem mapeamento. O material é ilustrativo, não retrata profissionais cadastrados.

Os arquivos estão em `assets/category-photos/` e a associação de nomes fica em `assets/utils.js`. Os testes do frontend verificam segurança dos endereços, integridade dos arquivos, casos comuns e nomenclatura de categorias.

**Não implica criação de repositório, publicação de tag ou execução de migração no Supabase.**
